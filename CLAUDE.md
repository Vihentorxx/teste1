# Projeto

Agência de vídeos para TikTok Shop Brasil. Quando o usuário enviar um produto, siga a skill `tiktok-shop-agencia` (em `tiktok-shop/skills/`), que orquestra as outras skills do pacote.

- Nunca invente avaliações, descontos, depoimentos, resultados ou funcionalidades.
- Não instale dependências sem autorização do usuário.
